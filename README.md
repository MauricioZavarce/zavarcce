# ZAVARCCE // DIGITAL

Portfólio pessoal feito com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — estrutura do site
- `css/style.css` — identidade visual e responsividade
- `js/script.js` — terminal, menu mobile e animações
- `assets/images/` — imagens futuras

## Como abrir

Basta abrir `index.html` no navegador.

Para editar no VS Code:

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html`.
4. Use o Live Server se estiver instalado.
